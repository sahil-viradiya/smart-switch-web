# Voice-over scripts

One line per scene. The computer voice reads them today. To use a real voice, record each line on a phone in a quiet room, name the files `1.m4a`, `2.m4a` and so on, put them in `marketing/voice/<video id>/`, and run `python marketing/build.py ads-video`. Keep each line about as long as the time shown.

The brand name is not spoken on purpose (a computer voice may mispronounce it). If you record the lines yourself, you may add "Euxora Digital" in the last line.
