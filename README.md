# Smart Switch — Product Marketing Website

A single Next.js (App Router) marketing website for the **Smart Switch** architectural electrical switch. Static-first, with one small endpoint that saves inquiries to an Excel sheet.

## Structure

```
smart_switch/
├── src/
│   ├── theme/          # ★ THE look: colors, typography, layout, motion, art palette (+ fonts)
│   ├── config/         # ★ THE facts: routes, pages (names/SEO/nav), cta (buttons), site (brand/contact), specs, images
│   ├── content/        # Page copy & data: product, features, use-cases, faq, home, rooms, tools, layers, catalog/ (generated product data)
│   ├── app/            # Routes (App Router): pages, layout, sitemap, robots, manifest, icon.svg
│   ├── components/
│   │   ├── art/        # Logo, Icons, ProductImage, SceneArt, OrbitDiagram
│   │   ├── motion/     # ScrollScene, Counter, Gauge, Marquee, Tilt, Parallax, ScrollProgress, SectionNav
│   │   ├── media/      # Lightbox, MediaGallery, Zoomable, MediaView, ProductFilm
│   │   ├── tools/      # WallChecker
│   │   ├── layout/     # Header, Footer, MobileDock, IntroSplash
│   │   ├── home/       # HeroVisual, ZoomReveal, FeatureWheel, HotspotRoom, RoomTabs
│   │   ├── catalog/    # CatalogBrowser (filters, URL sync, enquiry links)
│   │   ├── product/    # Configurator, ExplodedView
│   │   ├── forms/      # LeadForm, ContactForm, Field, FormSuccess
│   │   └── ui/         # Reveal, ButtonLink, CtaLink, PageHero, SectionHead, CtaBand, FaqAccordion...
│   ├── server/         # inquiries/ — Excel / Google Sheet storage, rate limit, ids (server-only)
│   ├── lib/            # validation/ (Zod), forms.ts, inquiry-client.ts, seo.ts
│   ├── types/          # Shared TypeScript types
│   └── styles/         # base.css, components.css, sections.css, scroll.css, catalog.css, animations.css (tokens only)
├── public/videos/      # film.mp4 (generated by scripts/film/make_film.py)
├── public/images/      # Panel cut-outs (catalog/), room photos (scenes/); scenes registered in src/config/images.ts
├── scripts/            # check-theme.mjs (guards the single sources of truth), catalogue/ (PDF to catalogue extractor), film/ (builds the product film)
├── marketing/          # 5 social posts + 30-second reel, captions, tracked links, claims check (python marketing/build.py)
├── docs/               # Requirements, architecture, page map, flows, design brief, customization guide
├── .env.example
└── package.json
```

Import with the `@/` alias, e.g. `import { ROUTES } from '@/config'`.

## Quick start

Requires Node.js 20+ (22/24 LTS recommended).

```bash
npm install
npm run dev          # http://localhost:3000
npm run type-check
npm run check         # type-check + guard against hard-coded colours/fonts/specs/paths
npm run build
```
